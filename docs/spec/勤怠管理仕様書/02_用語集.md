# 02 用語集

> 利用者向けの説明は「意味」列、エンジニア向けの対応は「コード上の名称」列を見てください。
> 時間はすべて内部では**分（整数）**、画面では **H:MM**（例 `10:05` ＝ 10時間5分）です。

## 1. 区分・社員まわり

| 用語 | 意味 | コード上の名称 |
|---|---|---|
| 長距離 | 長距離ドライバーの勤怠区分。拘束時間ログ・運行記録が元データ | `chokyo`（クラス `AM_Compute_Chokyo`、画面スラッグ `attendance-manager`） |
| 地場・事務 | 地場ドライバー・事務員の勤怠区分。打刻（MAT）が元データ | `jiba`（`AM_Compute_Jiba`、`attendance-manager-jiba`） |
| 地場フラグ（長距離画面の「地場」スイッチ） | 長距離の社員が、その日だけ地場勤務したことを示す。ONの日は打刻（MAT）から時間を取得 | 列 `jiba`（`am_chokyo_kintai_log.jiba`）、JS `.am-jiba-input` |
| 長距離フラグ（地場・事務画面の「長距離」スイッチ） | 地場・事務の社員が、その日だけ長距離勤務したことを示す。ONの日は運行記録から時間を取得。MAT の打刻に長距離フラグがあれば自動でON | 列 `chokyo`（`am_jiba_kintai_log.chokyo`）、MAT側 `long_distance`、JS `.am-chokyo-input` |
| 種別管理 | 職種ごとに「長距離」「地場・事務」のどちらの画面へ表示するかの設定 | `am_job_type_mapping` テーブル、AJAX `am_jobtype_*` |
| 所属 | 社員の所属部署。休日ルールは所属単位で設定する | `mst_affiliation`、`affiliation_id` |
| 職種 | 社員の職種（例: 長距離、郵便 など）。種別管理で画面区分に対応付ける | `mst_job_type`、`job_type_name` |
| 社員コード（社員No.） | 社員の番号 | `employee_code`（`emp_master.employee_code`） |
| 乗務員コード | 運行記録・拘束時間ログで使う、ドライバーの識別コード。**途中で変更されることがある** | `crew_code` |
| 社員ID | 社員マスタの不変の主キー。長距離の保存データはこれで管理する | `employee_id`（`emp_master.id`） |
| 乗務員コード履歴 | 1人の社員が使った複数の乗務員コードと、その使用期間の記録。社員管理プラグイン側が保持 | `wp_emp_crew_code_history`（`valid_from` / `valid_to` / `is_current`） |
| 現行乗務員コード | 社員マスタに現在登録されている乗務員コード | `emp_master.crew_code` |
| 対象月の使用コード | 対象月に有効だった乗務員コードの一覧（長距離画面の社員情報に表示） | `AM_DB::get_crew_codes_for_period()` |
| 未紐付け乗務員コード | 拘束時間ログにあるが、社員にも履歴にも結び付いていないコード | 設定画面 / `AM_DB::get_unlinked_crew_codes()` |

## 2. 時間・勤務の指標

| 用語 | 意味（画面） | コード上の名称・計算 |
|---|---|---|
| 始業時刻 / 終業時刻 | 仕事を始めた／終えた時刻。日またぎは `34:19` のように24を超えて表示 | `start_time` / `end_time` |
| 拘束時間 | 始業から終業までの全体の時間 | `kousoku_min` ＝ 終業−始業（日またぎは+24時間） |
| 労働時間 | 実際に働いた時間（長距離は運転＋積卸） | `labor_min`（長距離: `drive_min + cargo_min`）。打刻（MAT）側は MAT の算出値 |
| 運転時間 | 運転した時間 | `drive_min`（拘束時間ログ） |
| 積卸時間（荷役時間） | 荷物の積み下ろしの時間 | `cargo_min`（拘束時間ログの `cargo_min`＝荷役時間） |
| 休憩時間 | 拘束時間から労働時間を引いた残り（画面の「休憩時間」は**差し引きで算出**）。打刻（MAT）側は MAT の休憩分 | `break_calc_min` ＝ `max(0, 拘束−労働)` |
| 深夜時間 | 深夜帯（会社のルールによる）に働いた時間。**時間外深夜も含めた合計** | `midnight_min`（拘束ログの `midnight_min + overtime_midnight_min`） |
| 時間外深夜 | 時間外（残業）かつ深夜の時間。**深夜時間と日残業の両方へ算入**する会社ルール | `overtime_midnight_min` |
| 日残業 | その日の残業時間。長距離: 運行記録の「時間外＋時間外深夜」（無ければ 労働時間−8時間）。補正時間があれば加算 | `overtime_min`（行）/ `day_overtime_min`（週計） |
| 週残業 | 週の労働時間が40時間（2,400分）を超えた分 | `week_overtime_min` ＝ `max(0, 週労働(判定用) − 2400)` |
| 確定残業 | 週ごとの「日残業の合計」と「週残業」の**大きい方**。月の確定残業は、確定した週の合計 | `confirmed_overtime` ＝ `max(日残業合計, 週残業)` |
| 週（集計上の1週） | **日曜始まり〜土曜**の7日間 | `_build_weekly_static()` |
| 前月繰越残業（行） | 前月末をまたいだ週の、前月側の分を翌月先頭に表示する行 | `is_prev_carry` / `（前月繰越残業）` |
| 残業繰越（行）/ 次月繰越 | 月末をまたぐ週。確定は翌月に持ち越し、この月では「確定残業」を計上しない | `is_carryover` / `（残業繰越）` / バッジ「次月繰越」 |
| 繰越データ | 月末をまたぐ週の月内分を、翌月用にDBへ保存したもの | `am_chokyo_carryover` / `am_jiba_carryover` |
| 補正時間（点呼など・分） | 点呼等の時間として、労働時間・拘束時間へ**加算する分数**（既定10分）。日残業・週残業にも反映 | `hosei_min`（`apply_hosei()`） |
| 補正時間の適用開始月 | この月以降のみ補正時間が有効。それ以前の月は0扱い（過去の集計を変えない） | オプション `am_hosei_start_month` |
| 早退／遅刻 | 早退・遅刻した時間（`H:MM` 入力）。月間サマリで合計表示。**残業等の計算には使わない** | `hayatai_min`（列名は「早退」の読み `hayatai`） |
| 備考 | 自由記入欄（最大100文字） | `note` |

## 3. 勤怠種別・休日まわり

| 用語 | 意味 | コード上の名称 |
|---|---|---|
| 勤怠種別 | その日の扱い。8種類＋「―」（未設定） | `kintai_type` / `default_kintai`、定数 `Tanpopo_AttendanceManager::KINTAI_TYPES` |
| 出勤 | 勤務データのある日の既定 | `出勤` |
| 法定休 | **日曜日**で勤務データが無い日の既定（法定休日＝日曜） | `法定休` |
| 法定振替休 | 日曜出勤の代わりに取る休み（自動割当される） | `法定振替休` |
| 所定休 | 所属の休日ルールに該当する日で勤務データが無い日の既定（月2日まで） | `所定休` |
| 所定振替休 | 所定休日出勤の代わりに取る休み（現在は自動割当しない。手動選択は可） | `所定振替休` |
| 有給 | 有給休暇。承認済みの有給消化日は自動で「有給」になる | `有給` |
| 欠勤 | 欠勤 | `欠勤` |
| 緊急出動 | 緊急の出動。出勤日数にカウントされる | `緊急出動` |
| 法定休出勤 | 日曜に勤務データがある日。日付横に赤茶のバッジ「法定休出勤」を表示 | `houtei_kinmu` |
| 所定休出勤 | 所定休日に勤務データがある日。日付横に茶色のバッジ「所定休出勤」を表示 | `shitei_kinmu` |
| 振替なし法定休出勤 | 法定振替休と対応付けられなかった法定休出勤。**残業計算から除外**し、別枠で日数・時間を集計 | `unmatched_houtei_kinmu` / `unmatched_houtei_days` / `unmatched_houtei_labor_min` |
| 休日ルール（休日マスタ） | 「所属×曜日×第何週」を所定休日にする設定 | `am_holiday_rules`（`day_of_week`, `week_numbers`） |
| 手動（手動設定） | 利用者が勤怠種別を変更した行。自動判定で上書きされない | `is_manual` |
| データあり（has_data） | その日に元データ（運行記録／打刻）がある状態 | `has_data` |
| お盆出勤あり / お正月出勤あり | 集計一覧で、8月13日／1月1日に出勤があった社員に付く目視確認用バッジ | `_special_holiday_badge()` |

## 4. 外部システム・データ元

| 用語 | 意味 | コード上の名称 |
|---|---|---|
| 拘束時間ログ | 長距離ドライバーの日ごとの運転・荷役・拘束・残業・深夜などの集計値（乗務員コード×日付で1行）。CSVで取込可 | `wp_kousoku_log` |
| 運行記録（tenrec） | 日ごとの運行記録。`entries` に複数ドライバーの記録がJSONで入る。始業は `g1_time`、終業は `g7_time`→`g5_time`→`g3_time` の最後の入力値 | `wp_tenrec_daily`【g番号の業務上の意味は推定】 |
| 打刻（MAT） | 地場・事務の出退勤打刻ツール。丸め済み始業終業・労働・残業・深夜を公開APIで提供（v3.2.0〜） | `wp_mat_attendance_daily` / `mat_get_daily_by_month()` |
| 社員管理（employee-manager） | 社員・所属・職種マスタを管理する別プラグイン | `emp_get_affiliations()`, `emp_get_job_types()`, `emp_get_crew_codes_for_period()` |
| 有給管理（paid-leave-manager） | 有給の付与・消化を管理する別プラグイン | `wp_paidleave_grants` / `wp_paidleave_consumptions` |
| driver-report | 長距離の労働時間算出ロジックの「元ネタ」の別ツール。コード内コメントで「driver-reportと同じロジック」と参照される | （コメントのみ） |
| 60時間超 | 集計CSVの「確定残業が60時間を超えた分」列。`max(0, 確定残業 − 3600分)` | `class-am-summary-csv-exporter.php` |

## 5. 画面用語

| 用語 | 意味 |
|---|---|
| 集計表を開く | 長距離・地場・事務画面で、選んだ社員・月の月次表を表示するボタン（フォームの GET 送信） |
| 保存（更新） | 画面の編集内容をDBへ保存し、サマリを更新するボタン |
| 所属チップ | 社員セレクトを所属で絞るボタン群（「すべて」＋所属名） |
| 月間サマリ | 月の出勤日数・欠勤日数・休日出勤・振替なし法定休出勤・有給・労働時間・早退遅刻・確定残業の表 |
| 週計テーブル | 日次表の下の、週ごとの合計表 |
| アラート（警告） | 画面上部の黄色（注意）／赤（エラー）の帯。元データの不足や振替の過不足を知らせる |
