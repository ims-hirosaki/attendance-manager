# 03 利用者マニュアル

## 1. このシステムでできること

社員ごとの**1か月分の勤怠**を、運行記録や打刻のデータから**自動で組み立てて**表示します。あなたは内容を確認し、必要なところだけ**手で直して保存**します。

| メニュー | できること | 誰が使える？ |
|---|---|---|
| 長距離 | 長距離ドライバーの月の勤怠（日ごと・週ごと・月ごと）を確認・補正 | 勤怠メニューの利用権限がある人 |
| 地場・事務 | 地場ドライバー・事務員の月の勤怠を確認・補正 | 同上 |
| 集計一覧 | 全社員の月の集計を1つの表で確認、CSVで書き出し | 同上 |
| 拘束CSV取込 | 運行の拘束時間データをCSVで追加・修正 | **設定担当者のみ** |
| 設定 | 休日ルール、職種の振り分け、補正時間の開始月 | **設定担当者のみ** |

> 見えるメニューは、あなたに与えられた権限で変わります。「保存」ができない場合は、編集権限がない可能性があります。管理担当者に確認してください。

## 2. いちばん大切な約束ごと

1. **画面で直しただけでは保存されません。** 最後に必ず **「保存（更新）」** を押し、緑の「◯件を保存しました」が出たことを確認します。
2. **保存されるのは「あなたが直した内容」だけ**です。始業・終業・労働時間などの**時間は、元データから毎回自動で計算し直されます**（直接は書き換えられません）。時間がおかしいときは、元の運行記録・打刻を直します。
3. **勤怠種別を自分で変えた日は「手動」になり、以後は自動判定で変わりません。** 手動にした日を「自動」へ戻す操作は画面にはありません（管理担当者に相談）。
4. **続けて何日分も直す場合**: 保存したあとにさらに別の日を直すときは、いったん**ページを再読み込み（F5）**してから直すと確実です。（保存直後の画面更新で、手動の印が一時的に外れる場合があるため。12 の ISS-01 参照）

## 3. 基本の流れ（長距離・地場・事務 共通）

1. 左の WordPress メニューから **「勤怠管理」** を開き、**「長距離」** または **「地場・事務」** を選びます。
2. 所属のボタン（「すべて」「◯◯」…）が出ていれば、先に所属を選ぶと社員名が絞れます。
3. **「社員名」** と **「対象月」** を選び、**「集計表を開く」** を押します。（社員名を選ぶまでボタンは押せません）
4. 画面の見出しに「2026-09　◯◯さんの集計表」と出ます。**左右の矢印**で前の月・次の月へ移れます。
5. 上から順に確認します:
   - 上部の **注意の帯**（黄色・赤）があれば読む
   - **日ごとの表**
   - その下の **週ごとの合計**
   - いちばん下の **月間サマリ（月の合計）**
6. 直すところがあれば直し、**「保存（更新）」**。

## 4. 長距離画面の見方

### 4.1 社員の情報
- **現行乗務員コード**: 今登録されている乗務員コード。
- **対象月の使用コード**: その月に実際に使われたコード。月の途中でコードが変わった人は複数表示されます。**コードが変わっても、1人の1か月分として合算して表示**されます。

### 4.2 日ごとの表（列の意味）

| 列 | 意味 |
|---|---|
| 日付 | 月日と曜日。日曜は薄い赤、土曜は薄い青の行。データが無い平日は文字が灰色 |
| 勤怠種別 | その日の扱い（下の 4.3）。自動で入ります。変更できます |
| 始業時刻・終業時刻 | 仕事を始めた／終えた時刻。日をまたぐ場合は `34:19`（翌日10:19）のように24を超えて表示 |
| 拘束時間 | 始業から終業までの全体の時間 |
| 労働時間 | 実際に働いた時間（長距離は「運転＋積卸」） |
| 運転時間・積卸時間 | 運転した時間・荷物の積み下ろしの時間 |
| 休憩時間 | 拘束時間から労働時間を引いた時間 |
| 深夜時間 | 深夜に働いた時間（深夜の残業もここに含む） |
| 日残業 | その日の残業時間。残業があると赤い太字 |
| 地場（スイッチ） | その日だけ地場勤務をしたときに ON（4.5） |
| 補正時間（点呼など・分） | 点呼などの時間を**分**で入力。標準は10分（4.6） |
| 早退／遅刻 | 早退・遅刻した時間を「0:30」の形で入力 |
| 備考 | メモ（100文字まで） |

### 4.3 勤怠種別（自動で決まる仕組み）

| 種別 | 自動で入る条件／意味 |
|---|---|
| 出勤 | その日に運行記録・打刻のデータがある |
| 法定休 | **日曜日**でデータが無い日 |
| 法定振替休 | 日曜に出勤した代わりの休み。システムが自動で割り当てる（4.4） |
| 所定休 | 所属の休日ルール（第2・第4土曜など）に当たる日でデータが無い日（**月に2日まで**） |
| 所定振替休 | 所定休日に出勤した代わりの休み。**現在は自動で入らない**。必要なら手で選ぶ |
| 有給 | 有給管理で承認された消化日は**自動で「有給」**になる。手で選ぶことも可 |
| 欠勤 | 手で選ぶ |
| 緊急出動 | 手で選ぶ。出勤日数に数えられる |
| ―（空欄） | 該当なし（出勤も休みも決まらない日） |

### 4.4 日曜出勤と「振替休」
- 日曜にデータがある日には、日付の横に赤茶色の **「法定休出勤」** の印が出ます。
- システムはその日より**後の日で「勤怠種別が空欄・データなし・日曜でない・所定休日でない・手動でない」最初の日**を、自動で **「法定振替休」**（「◯◯/◯◯(日)の振替」と表示）にします。
- 割り当てる日が月内に無いと、赤い帯で「**◯◯/◯◯(日)の振替休を割り当てられる日がありません**」と出ます。**月をまたいだ振替は自動ではされません。**
- **振替休に対応付けられなかった日曜出勤は「振替なし法定休出勤」**として扱われ、**残業の計算から外れ**、月間サマリで別に（日数／労働時間で）表示されます。
- 所定休日に出勤した日には、茶色の **「所定休出勤」** の印が出ます。

### 4.5 「地場」スイッチ（長距離画面）
長距離の人が**その日だけ地場の仕事をした**場合に ON にします。ON の日は、運行記録ではなく**打刻（出退勤）のデータ**から時間が取られます。
- ON/OFF を変えて保存すると、**画面全体が自動で読み込み直されます**（「ページを更新して反映します」と出ます）。

### 4.6 補正時間（点呼など）
- 点呼などの時間を、**労働時間・拘束時間に足す**ための分数です。標準は **10分**。必要に応じて変更できます（0にすると加算なし）。
- **入力できる日**: 始業・終業の時刻がある日 かつ **「補正時間の適用開始月」以降**の月。それ以外の日は入力欄がグレーで固定（開始月より前は、マウスを乗せると理由が出ます）。
- 反映先:
  - **日残業**: 「労働時間＋補正時間」が8時間を超えた分が日残業に加わります。
  - **週ごとの合計・月間サマリ**の労働時間・拘束時間、および週40時間の残業判定。
- **注意**: 日ごとの表の「労働時間」の列は**補正を含まない数字**です。補正が含まれるのは、日残業と、週・月の合計です。

### 4.7 早退／遅刻
「0:30」「1:15」のように**時:分**で入力します。**分だけの数字（例 `30`）は30時間として扱われる**ので注意してください。月間サマリの「早退遅刻時間」に合計されます（残業や労働時間の計算には使われません）。

## 5. 地場・事務画面の見方
基本は長距離画面と同じです。違いは次のとおり。

- 社員は **社員コードで選ぶ**（表示は「[コード] 氏名」）。
- 時間のもとになるのは **打刻（出退勤）データ**です。**始業・終業時刻などは画面では直せません**。
- 日ごとの表に **「長距離」スイッチ**があります。**地場・事務の人がその日だけ長距離の仕事をした**ときに ON にします。ON の日は運行記録から時間が取られます。
  - 打刻ツール側で長距離の印が付いている日は、**自動で ON** になります。
  - ON/OFF を変えて保存すると画面全体が読み込み直されます。
- **補正時間は、「長距離」が ON の日だけ入力できます**（標準10分）。OFF の日は0で固定。
- 「長距離」を ON にしても運行記録（拘束時間データ）が無い日は、始業・終業のみ表示され、労働時間などは空欄になります。

## 6. 週ごとの合計と月の合計

### 6.1 週ごとの合計の見方
- **1週間は日曜〜土曜**です。月初・月末は、その月の分だけを集計します。
- 列: 期間／開始日／終了日／日数／拘束／労働／運転／積卸／休憩／深夜／**日残業**／**週残業**／**確定残業**。
- **日残業** … その週の日ごとの残業の合計。
- **週残業** … その週の労働時間が**40時間を超えた分**。
- **確定残業** … 「日残業の合計」と「週残業」の**大きい方**。実際に残業として確定する数字です。

### 6.2 月をまたぐ週
月末が週の途中（土曜でない）の場合:
- その週は **「（残業繰越）」** の行になり、**週残業の欄に黄色の「次月繰越」**が出ます。この月では確定残業を出さず、**翌月に持ち越して確定**します。
- **翌月の最初**には、青い斜体の **「（前月繰越残業）」** 行が出ます。この行は参考表示で、**翌月の第1週の「週40時間」の判定に前月分が足される**ために使われます。
- 月の合計では、「前月繰越」行は含まず、「（残業繰越）」行の労働時間などは含みます（確定残業だけは翌月に計上）。

> **月初の大事な手順**: 翌月への繰越は「**前月を表示（計算）したとき**」に保存されます。前月の元データを直したあとは、**前月を一度開き直す（または集計一覧を読み込む）**ことで、翌月の繰越が更新されます。

### 6.3 月間サマリ（月の合計）
| 項目 | 意味 |
|---|---|
| 出勤日数 | 「出勤」と「緊急出動」の日数 |
| 欠勤日数 | 「欠勤」の日数（1日以上で赤） |
| 休日出勤日数 | 法定休出勤＋所定休出勤の日数（オレンジ） |
| 振替なし法定休出勤 | 振替休が付かなかった日曜出勤の日数 ／ その労働時間 |
| 有給消化日数 | その月の有給消化（有給管理から）。データが無いと「―」 |
| 有給残日数 | **現在有効な**有給の残り（対象月ではなく今日時点）。データが無いと「―」 |
| 労働時間 | 月の労働時間の合計（補正時間を含む） |
| 早退遅刻時間 | 入力した早退・遅刻の合計 |
| 確定残業時間 | 月の確定残業の合計（残業があると赤） |

## 7. 画面上部の注意（警告）の読み方
黄色=注意、赤=確認が必要。**表示されたら、元データ（運行記録・打刻）や勤怠種別に不足・食い違いがないか確認**してください。

| 表示される文章（要約） | 意味と対処 |
|---|---|
| 法定休の合計（法定休◯日＋法定振替休◯日＝◯日）が正常範囲（4〜5日）を外れています | 日曜の休み（＋振替休）が月に4〜5日になっていない。日曜出勤が多い、または振替が足りない可能性 |
| 所定休が2日を超えています | 所定休が3日以上になっている（手で選んだ分がある）。確認する |
| 法定休出勤（◯回）と法定振替休（◯日）の数が一致していません | 日曜出勤の回数と振替休の数が違う。振替の割当・手動設定を確認 |
| 所定休出勤（◯回）と所定振替休（◯日）の数が一致していません | 所定休日に出勤した回数と所定振替休の数が違う（振替が任意の場合は出ることがある） |
| ◯◯/◯◯(日)の振替休を割り当てられる日がありません | 日曜出勤の振替先が月内に無い（4.4） |
| ◯◯に乗務員コード A と B の拘束時間データが重複しています… | 同じ人の複数コードに同じ日のデータがある。**先に読み込んだ方だけ**使われている。元データやコードの有効期間を管理担当者に確認 |
| ◯◯の保存済み勤怠編集情報が複数コードに存在します。自動保存せず確認してください | 過去に別コードで保存した編集が重複。管理担当者に連絡 |
| この月の前月繰越データが複数の乗組員コードに存在するため、自動適用していません | 繰越が重複。管理担当者に連絡 |

## 8. 集計一覧（全社員の月の集計）
1. **「集計一覧」** を開き、**対象月**を選び **「読み込む」**。（開いただけでは表示されません。人数が多いと少し時間がかかります）
2. 長距離・地場・事務の全社員の、出勤・欠勤・休日出勤・振替なし法定休出勤・有給・労働時間・早退遅刻・確定残業が並びます。
3. 8月に**8/13**、1月に**1/1**に出勤した人には、氏名の横に **「お盆出勤あり」「お正月出勤あり」** の印が出ます（目で確認するための印）。
4. **「CSV出力」** で、同じ月の集計をCSV（Excelで開ける形式）でダウンロードできます。**CSVの時間は「時間の10進数」**（例 `10.1` ＝ 約10時間6分）で、画面の「10:05」のような「時:分」表記とは違います。
5. この画面は見るだけです。直すときは、その人の「長距離」「地場・事務」画面で行います。

> CSVには、画面の表とは別の項目（点呼時間の加算、60時間超の分、所定休日勤務実績など）も含まれます。詳しくは 08_CSV仕様。

## 9. 設定（設定担当者のみ）

### 9.1 休日マスタ（所属ごとの所定休日）
「何曜日の第何回目を休みにするか」を所属ごとに決めます。長距離・地場・事務の両方に効きます。
- **追加**: 所属 → 曜日 → 対象週（例 第2・第4なら `2,4`。半角のカンマ）→ **保存**。
- 「第◯週」は**その月のその曜日の◯回目**です（例: 第2土曜＝その月の2回目の土曜日）。
- **編集**: 一覧の「編集」で上の入力欄に呼び出して直し、「更新」。やめるときは「キャンセル」。**編集して保存するとルールは有効に戻ります。**
- **無効化／有効化**: 消さずに一時的に止める／再開する。
- **削除**: 確認画面で同意すると削除。
- 変更すると**その所属の勤怠の「所定休」判定が変わります**。変更前に所属・曜日・週が正しいか確認してください。

### 9.2 種別管理（職種をどの画面に出すか）
- 職種ごとに **「長距離」「地場・事務」** のどちらかを選ぶと、**選んだ瞬間に保存**されます（状態が「設定済」）。
- 「未設定」の職種の社員は、どちらの画面にも出ません。**職種を設定しないと社員が選べません。**
- 一度設定した職種を「未設定」へ戻す操作はありません（別の区分へ変更は可能）。
- 職種の一覧は社員管理のデータから自動で出ます。職種自体が出ないときは、先に社員管理で職種を登録します。

### 9.3 補正時間の適用開始月
- 補正時間を有効にする**最初の月**を決めます。**それより前の月は補正時間が0扱いで、過去の集計は変わりません**。
- 変更前に、過去月の数字が変わっても良いか確認してください。

### 9.4 未紐付け乗組員コード
拘束時間データにあるのに、社員にも履歴にも結び付いていない乗務員コードの一覧と、データ移行の状況（件数）が見られます。紐付けは**社員管理の社員編集画面で「過去コードを追加」**して行います（この画面では操作できません）。

## 10. 拘束時間CSV取込（設定担当者のみ）
運行の拘束時間データが**未反映・欠けている**ときに、CSVで追加・修正します。
1. **「ひな形CSVをダウンロード」**（見出しは日本語）。
2. ひな形に行を入力して、CSV（UTF-8）で保存。
3. **「修正済みCSVを選択」**してから **「CSVを取り込む」**。
4. 結果（処理対象・新規追加・上書き・既存スキップ）が表示されます。

大事なこと:
- **標準では、同じ「乗務員コード＋日付」が既にある行はスキップ**（上書きしません）。
- 「既存行を上書きする」は**イレギュラー対応のときだけ**。事前にバックアップを取ってから。
- **1行でも間違いがあると、ファイル全体が取り消されます**（途中まで反映されることはありません）。エラーの行番号を見て直して、もう一度取り込みます。
- 取込後は、対象の社員・月を開いて数字を確認してください（翌月の繰越にも影響）。

## 11. 月次の作業の流れ（例）

| 順 | 作業 | 画面 |
|---|---|---|
| 1 | 拘束時間データの不足があれば CSV 取込（設定担当者） | 拘束CSV取込 |
| 2 | **前月の「集計一覧」を読み込む**（翌月への繰越を最新にする） | 集計一覧 |
| 3 | 社員ごとに日ごとの表を確認 → 勤怠種別・スイッチ・補正・早退遅刻・備考を直す → **保存（更新）** | 長距離／地場・事務 |
| 4 | 警告が出ていないか、週・月の合計に不自然な点がないか確認 | 同上 |
| 5 | 集計一覧で全員を確認し、必要ならCSV出力 | 集計一覧 |

## 12. よくある操作

| やりたいこと | 方法 |
|---|---|
| 日曜出勤をした | 何もしなくてよい。「法定休出勤」の印が付き、後の空き日に「法定振替休」が自動で入る。警告が出たら 7 を確認 |
| 休日に出勤したが、振替休は取らない | 所定休日は振替が任意。日曜の場合は「振替なし法定休出勤」になり残業計算から外れる（4.4） |
| 欠勤にしたい | その日の勤怠種別を「欠勤」にして保存 |
| 有給にしたい | 有給管理で承認されていれば自動。されていなければ勤怠種別を「有給」にして保存（手動扱い） |
| 遅刻した時間を残したい | 早退／遅刻に「0:30」のように入力して保存 |
| 長距離の人が1日だけ地場だった | 長距離画面で、その日の「地場」を ON → 保存（画面が再読込される） |
| 地場の人が1日だけ長距離だった | 地場・事務画面で、その日の「長距離」を ON → 保存（打刻側で印があれば自動） |
| 点呼の時間を日によって変えたい | 補正時間（分）を直して保存 |
| 先月の数字を変えたい | 先月の画面で直して保存 → **先月を開き直して**翌月の繰越を更新 |

## 13. 困ったとき

| 状況 | 確認すること |
|---|---|
| 社員名が選べない・出てこない | 所属の絞り込みを「すべて」に戻す／設定の「種別管理」でその職種が設定済か／その社員が有効（在籍）か／（長距離）乗務員コードが登録されているか |
| 「集計表を開く」が押せない | 社員名が選ばれているか、対象月が入っているか |
| 変更が残っていない | 「保存（更新）」を押したか、「◯件を保存しました」が出たか |
| 保存で「保存に失敗しました」 | 画面を更新して再度。続く場合は管理担当者へ（メッセージの文章を伝える） |
| 保存で「通信エラー」や何も起きない | 接続を確認して再度。**保存の権限がない可能性**もあります |
| 保存したのに、さっき手で直した別の日の種別が自動に戻った | 保存直後に続けて保存した場合に起こり得ます（ISS-01）。**保存後は再読み込みしてから**次の編集をしてください。戻った日は再度設定します |
| 労働時間が空欄・0 | その日の元データ（運行記録／打刻）が無い、または運転時間が入っていない。元データを確認 |
| 数字が合わない | 05 の計算ルールを確認（補正時間は日次の労働時間の列に含まれない、など） |
| 翌月の繰越行が出ない・古い | 前月を一度開き直す（または集計一覧を読み込む） |
| 設定メニューが見えない | 設定の権限がない。設定担当者へ依頼 |
| 「DBエラー」の赤い帯 | 管理担当者へ。表示された文章を伝える |

**連絡するときに伝えると早いこと**: 社員名、対象月、行った操作、画面に出た文章、スクリーンショット。

- [ ] 補正時間・早退遅刻・備考が必要に応じて入っている
