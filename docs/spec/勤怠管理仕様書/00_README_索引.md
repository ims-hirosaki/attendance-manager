# 勤怠管理プラグイン 仕様書セット 索引

## 1. このドキュメント群について

有限会社たんぽぽ運送の WordPress 管理画面プラグイン「**勤怠管理**（attendance-manager）」を、**ソースコードから逆算して**文書化した仕様書セットです。

- 目的: NotebookLM のソース、または Gem（カスタム Gem）の参照ナレッジとして使い、**利用者とエンジニアの両方**からの質問に答えられるようにすること。
- 作成方法: 全 PHP / JavaScript / テンプレート / ワークフロー / 既存ドキュメントを読み、計算ロジックは実際に PHP で動かして挙動を検証しました（数値例は検証済み）。
- 元の設計書は存在しません。**コードが唯一の正**であり、本書は「コードが実際にどう動くか」を記述しています。

## 4. 回答時の注意（Gem のシステム指示にそのまま使えます）

1. **質問者を見分ける**: 画面操作・業務用語で質問されたら利用者向け（03・11・02）を中心に、専門用語を避けて答える。関数名・テーブル名・コードに触れる質問ならエンジニア向け（04〜10）で答える。
2. **根拠の明示**: 仕様の回答には、できるだけ文書ID（例: `BR-12`）または参照元ファイル名を添える。
3. **確度ラベルを尊重する**: 本書では記述の確度を次のラベルで区別している。回答でも区別して伝えること。
   - **【確定】** … コードから直接読み取れる事実
   - **【推定】** … 名称・コメントから推測した意図（業務上の設計意図など）
   - **【要確認】** … コード上は不整合・曖昧で、担当者への確認が必要
4. **本書に無いことは推測で断定しない**: 例えば法令（労働基準法）の解釈や、他プラグイン（拘束時間管理・打刻ツール・社員管理・有給管理）の内部仕様は、本書では「この勤怠管理プラグインから見えている範囲」しか記述していない。
5. **時間表記**: 画面の「H:MM」表記（例 `10:05`）は「10時間5分」。内部は分単位の整数（例 605）。CSV出力のみ「時間の10進数」（例 `10.1`）。
6. **数値の例示は本書の検証済みの例を使う**: 05 の「計算例」は実際にコードを実行して確認済み。

## 8. NotebookLM / Gem への取り込み方

### 8.1 NotebookLM
- 13 ファイルをそのまま「ソース」として追加できます（各ファイルは小さく、章立て・ID付きで引用しやすい構成）。
- 追加後に試す質問例: 「補正時間が日残業へどう反映されるか、計算例つきで説明して」「日曜出勤をしたらどうなる？（利用者向けに）」「集計CSVの長距離の既知の問題は？」

### 8.2 Gem（カスタム Gem）
Gem の知識ファイルは**最大10ファイル**までのため、13ファイルを次のとおり10ファイルに統合してアップロードしてください（`docs/spec` で実行）。

```bash
mkdir -p gem
cat 00_*.md 01_*.md 02_*.md > gem/gem_01_概要と用語.md
cp  03_*.md gem/gem_02_利用者マニュアル.md
cp  04_*.md gem/gem_03_画面仕様.md
cp  05_*.md gem/gem_04_業務ロジック仕様.md
cp  06_*.md gem/gem_05_データ仕様.md
cat 07_*.md 08_*.md > gem/gem_06_APIとCSV仕様.md
cp  09_*.md gem/gem_07_設定と運用ガイド.md
cp  10_*.md gem/gem_08_開発保守ガイド.md
cp  11_*.md gem/gem_09_FAQ.md
cp  12_*.md gem/gem_10_既知の課題.md
```

**Gem の指示（システムプロンプト）ひな形**:

```
あなたは「勤怠管理プラグイン（有限会社たんぽぽ運送）」の専門アシスタントです。
回答は、添付の仕様書だけを根拠にしてください。仕様書に無いことは「仕様書には記載がありません」と答え、推測で断定しないでください。
- 質問者が利用者（画面操作・業務用語）なら、専門用語やコード名を避け、手順を番号付きで簡潔に答える。
- 質問者がエンジニア（関数名・テーブル・API・改修）なら、ファイル名・関数名・業務ルールID（BR-nn）・API ID・ISS-nn を添えて正確に答える。
- 数値の計算を聞かれたら、仕様書の計算式と計算例（05）に基づき、途中式を示す。
- 【確定】【推定】【要確認】のラベルは回答にも反映する。バグ疑い（ISS-nn）に関係する質問では、その旨と暫定回避策を伝える。
- 時間は画面表記（H:MM）と分の両方を、CSVは時間の10進数であることを区別して示す。
```

### 8.3 更新のしかた
コード変更後は、該当する文書を更新してください（対応表は 10 §6）。特に、計算ルールを変えたら 05（BR と計算例）、画面項目は 04、DB は 06、API は 07、既知の問題が解消したら 12 を直し、NotebookLM / Gem のソースを入れ替えます。
