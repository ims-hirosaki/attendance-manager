# 08 CSV仕様

## 1. 拘束時間CSV取込

### 1.1 目的【確定】
拘束時間ログ（`wp_kousoku_log`）に**未反映・欠損しているデータを追加または補正**するための取込機能。権限: `manage_custom_plugin_settings`。

### 1.2 利用手順
1. 「拘束CSV取込」画面で **「ひな形CSVをダウンロード」**（日本語見出しの空CSV、UTF-8 BOM付き）。
2. 必要な行を入力して CSV（UTF-8）で保存。
3. 「修正済みCSVを選択」→（必要なら「既存行を上書きする」にチェック）→ **「CSVを取り込む」**。
4. 画面上部に結果（処理対象・新規追加・上書き・既存スキップ件数）が表示される。**エラーのときは全体が取り消される**。

### 1.3 ファイル条件【確定】
| 項目 | 条件 |
|---|---|
| 拡張子 | `.csv` |
| サイズ | 1バイト以上 20MB（20,971,520バイト）以下 |
| データ行数 | 最大 100,000 行（空行を除く） |
| 文字コード | UTF-8（BOM可）。不正なUTF-8は行エラー |
| 区切り | カンマ、囲み文字 `"` |
| 実行時間 | 最大300秒（`set_time_limit`）、メモリ上限を管理画面用に引き上げ |

### 1.4 ヘッダー（見出し）
**ひな形は24列（日本語見出し）**。次のどちらの形式も受け付ける。見出しは**日本語・英語（DB列名）の混在も可**（日本語は内部で列名へ変換）。列の過不足・重複はエラー。

| 日本語見出し | DB列名 | 型 | 必須 | 備考 |
|---|---|---|---|---|
| 乗務員コード | `crew_code` | 文字列（最大20） | ○ | 前後空白除去 |
| 日付 | `work_date` | `YYYY-MM-DD` | ○ | 実在日付のみ |
| 始業時刻 | `start_time` | `HH:MM` または `HH:MM:SS` | ○ | 0〜23時 |
| 終業時刻 | `end_time` | 同上 | ○ | **24時以上は不可**。日またぎは次列で表す |
| 終業翌日フラグ | `end_next_day` | 整数 0/1 | ○ | 0 または 1 |
| 運転時間（分） | `drive_min` | 整数 | ○ | |
| 重複運転時間（分） | `drive_overlap_min` | 整数 | 任意 | NULL可 |
| 荷役時間（分） | `cargo_min` | 整数 | 任意 | NULL可（画面の「積卸時間」） |
| 重複荷役時間（分） | `cargo_overlap_min` | 整数 | 任意 | |
| 休憩時間（分） | `break_min` | 整数 | 任意 | |
| 重複休憩時間（分） | `break_overlap_min` | 整数 | 任意 | |
| 拘束時間小計（分） | `kousoku_subtotal_min` | 整数 | ○ | |
| 重複拘束時間小計（分） | `kousoku_overlap_min` | 整数 | 任意 | |
| 拘束時間合計（分） | `kousoku_total_min` | 整数 | ○ | |
| 拘束時間累計（分） | `kousoku_cumul_min` | 整数 | ○ | |
| 前運転平均（分） | `drive_avg_before_min` | 整数 | 任意 | |
| 後運転平均（分） | `drive_avg_after_min` | 整数 | ○ | |
| 休息時間（分） | `rest_min` | 整数 | 任意 | |
| 実働時間（分） | `actual_work_min` | 整数 | ○ | |
| 時間外時間（分） | `overtime_min` | 整数 | 任意 | |
| 深夜時間（分） | `midnight_min` | 整数 | 任意 | |
| 時間外深夜時間（分） | `overtime_midnight_min` | 整数 | 任意 | |
| 摘要1 | `remarks1` | 文字列 | 任意 | |
| 摘要2 | `remarks2` | 文字列 | 任意 | |

- **互換形式**: phpMyAdmin の全27列CSV（上記24列＋`id`, `created_at`, `updated_at`）も取り込める。24列形式と27列形式の**どちらかに完全一致**する必要がある（中間は不可）。
- 「任意」列は空欄または文字列 `NULL` で NULL になる。「必須」の整数列は空欄不可。整数は `-?\d+` のみ（`1.5` や `1,000` は不可）。
- 日付の書式は `YYYY-MM-DD`、全27列形式の `created_at`/`updated_at` は `YYYY-MM-DD HH:MM:SS`。

> **重要（業務）**: 本プラグインの長距離計算が実際に使うのは `crew_code, work_date, start_time, end_time, end_next_day, drive_min, cargo_min, overtime_min, midnight_min, overtime_midnight_min` です（05 BR-03〜05）。他の列は必須・任意の入力検証はされますが、勤怠計算には使われません。

### 1.5 既存行の扱い【確定】
既存判定キー: **`crew_code` + `work_date`**（`wp_kousoku_log` を検索）。

| モード | 既存行あり | 既存行なし |
|---|---|---|
| 標準（チェックなし） | **スキップ**（件数に計上） | 新規追加 |
| 「既存行を上書きする」 | **UPDATE**（`id`・`crew_code`・`work_date` 以外の全列をCSV値で更新） | 新規追加 |

- 上書き時はブラウザの確認ダイアログ「既存行をCSVの値で上書きします。実行してよろしいですか？」が出る。
- 画面の注意書き: 上書きは**イレギュラー対応時のみ**、事前に `wp_kousoku_log` をバックアップする。
- 新規追加で CSV に `id` がある場合、既にその ID が別レコードで使用されているとエラー。
- 新規行の `id`・`created_at`・`updated_at` は（CSVに無ければ）DBが自動設定。

### 1.6 トランザクション・エラー【確定】
- **全体が1トランザクション**。1行でも不正（形式・桁・DBエラー）があれば `ROLLBACK` し、**ファイル全体が取り消される**（部分取込にならない）。画面には「エラーが発生したため、今回の変更はすべて取り消されました。」と該当行番号付きのメッセージが出る。
- 代表的なエラーメッセージ:
  - `CSVファイルを選択してください。` / `拡張子が .csv のファイルを選択してください。` / `CSVファイルは20MB以下にしてください。`
  - `CSVヘッダーに重複したカラムがあります。` / `CSVヘッダーがひな形と一致しません。画面から最新のひな形をダウンロードしてください。`
  - `{n}行目: カラム数がヘッダーと一致しません。`
  - `{n}行目: {列} は必須です。` / `… は整数で入力してください。` / `… は YYYY-MM-DD 形式で入力してください。` / `… は HH:MM:SS 形式で入力してください。` / `… の時刻が不正です。`
  - `{n}行目: end_next_day は0または1で入力してください。`
  - `データ行が100,000件を超えています。ファイルを分割してください。`
  - `テーブルに必要なカラムがありません: …`（`wp_kousoku_log` の構造不足）
- 結果は transient に5分間保存され、リダイレクト後に1度だけ表示される。

### 1.7 取込後の影響
- 取込は `wp_kousoku_log` を直接変更するため、**長距離の月次表・集計・（月末をまたぐ週の）翌月繰越に影響**する。取込後は、該当月（と翌月）を開き直して確認すること。（繰越は前月の再計算時に更新される：05 BR-22）

## 2. 集計CSV出力

### 2.1 目的【確定】
「集計一覧」画面の **CSV出力** ボタンで、選んだ月の**全対象社員**の月次集計を CSV でダウンロードする。権限: `access_custom_plugins`。ファイル名 `attendance-summary-YYYY-MM.csv`。

- 先頭に UTF-8 BOM を付与（Excel で日本語が開けるように）。
- 実装コメントによれば「**将来、全ツール共通のCSV出力に移行することを前提とした一時的な出力**」。
- 画面の月を変更すると、ボタンのリンクの `year_month` が JS で更新される（※**CSVは画面の「読み込む」結果ではなく、サーバーが再計算した値**）。
- 出力順: 長距離の社員 → 地場・事務の社員（各社員コード順）。

### 2.2 列（固定21列）

| # | 列名 | 内容 |
|---|---|---|
| 1 | 氏名 | |
| 2 | 職種 | 職種名 |
| 3 | 総労働時間（点呼時間含む） | 月間労働時間（週集計の労働合計）。**職種が「長距離」または「郵便」の場合、出勤日数×10分を追加加算** |
| 4 | 確定残業時間 | 月の確定残業 |
| 5 | 確定残業が60時間を超えた分の数値 | `max(0, 確定残業 − 3,600分)` |
| 6 | 深夜時間 | 週集計の深夜合計 |
| 7 | 出勤日数 | 出勤＋緊急出動 |
| 8 | 法定休日出勤日数 | **振替なし法定休出勤**の日数（05 BR-19） |
| 9 | 有給消化日数 | 有給管理のデータがある場合のみ数値、無ければ空 |
| 10 | 法定休日労働時間 | **振替なし法定休出勤**の労働時間（補正含まず） |
| 11 | 積卸時間 | 週集計の積卸合計 |
| 12〜21 | 所定休日勤務実績_1 〜 _5 と各「の労働時間」 | **所定休出勤**の日（`YYYY-MM-DD`）とその日の労働時間。最大5件（日付順）、無い枠は空欄 |

### 2.3 時間の表記
**時間の10進数**。分を60で割り、**小数第2位を四捨五入して小数第1位まで**（`number_format(分/60, 1)`）。例: 605分→`10.1`、90分→`1.5`、負数は0に丸める。画面の `H:MM` 表記とは異なる。

### 2.4 注意点（コード読解）
- 集計CSVの「総労働時間（点呼時間含む）」の**点呼加算（出勤日数×10分）は、補正時間機能（2026-09-29 導入）より前に追加された処理**。補正時間が有効な月は、週集計の労働時間に既に補正が含まれるため、**二重に加算される可能性がある**。【要確認：ISS-04】
- **長距離社員のCSV出力は、現行コードでは社員の識別子が合わず誤動作する可能性が高い**。【要確認：ISS-02（優先度高）】
